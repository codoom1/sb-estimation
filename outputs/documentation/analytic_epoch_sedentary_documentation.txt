Dataset documentation: analytic_epoch_sedentary.csv

Generated from reports/source/manuscript_main.Rmd using the 1h epoch analysis.
Final analytic sample size represented: 14,534 participants.
Number of epoch-level rows: 2,406,024.
Selected sleep/nonwear cutoff: 90.9%.

Purpose
This epoch-level dataset is intended to support future epidemiologic research that needs repeated accelerometer summary records rather than only participant-level usual daily means. Each row represents one native analysis epoch for one NHANES participant-day.

Source data and processing overview
The source accelerometer summaries combine CHAP wrist posture predictions with SWaN sleep/nonwear classifications. Each epoch retains the CHAP-derived sitting percentage and SWaN-derived sleep/nonwear percentage. The selected sleep/nonwear cutoff is applied to flag whether the epoch contributes to waking sedentary-time estimation.

Unit of analysis
The analytic unit is the participant epoch. For this render, the native epoch is 1 hour. Participant-level manuscript estimates are still calculated from participant summaries; this file is provided for future repeated-measure, time-of-day, day-level, and sensitivity analyses.

Derived epoch-level quantities
is_waking_epoch is TRUE when percent_sleep is less than the selected cutoff.
sed_hours_epoch equals percent_sedentary_wrist / 100 multiplied by epoch_duration_hours for waking epochs, and 0 for epochs classified as sleep/nonwear.
wake_hours_epoch equals epoch_duration_hours for waking epochs, and 0 otherwise.
sleep_nonwear_hours_epoch equals epoch_duration_hours for epochs classified as sleep/nonwear, and 0 otherwise.
sleep_nonwear_fraction_hours equals percent_sleep / 100 multiplied by epoch_duration_hours. This is a fractional SWaN summary and is not the binary cutoff-based exclusion measure.
sitting_fraction_hours equals percent_sedentary_wrist / 100 multiplied by epoch_duration_hours before applying the sleep/nonwear cutoff.

Survey design
Exam_weight_recal, PSU, and Stratum are included for linkage and reproducibility. Because NHANES weights are assigned to participants rather than epochs, users should not treat each epoch as an independently weighted population observation without accounting for repeated measures within participants. Participant-level national estimates should use analytic_participant_sedentary.csv.

Variable dictionary
ID: NHANES participant identifier.
Dataset: NHANES cycle, either 2011-2012 or 2013-2014.
Day: participant wear day/date identifier from the analysis-ready accelerometer summaries.
DayType: weekday/weekend classification.
Hour: hour of day.
epoch: within-hour epoch index; 1 for hourly data.
epoch_duration_hours: duration represented by the row, in hours.
cutoff: selected sleep/nonwear percentage cutoff used to define waking epochs.
is_waking_epoch: TRUE if percent_sleep is below cutoff.
percent_sedentary_wrist: CHAP-derived sitting percentage for the epoch.
percent_sleep: SWaN-derived sleep/nonwear percentage for the epoch.
sed_hours_epoch: cutoff-aware waking sedentary hours contributed by the epoch.
wake_hours_epoch: cutoff-aware waking hours contributed by the epoch.
sleep_nonwear_hours_epoch: cutoff-aware sleep/nonwear hours contributed by the epoch.
sleep_nonwear_fraction_hours: fractional sleep/nonwear hours implied by percent_sleep.
sitting_fraction_hours: fractional sitting hours implied by percent_sedentary_wrist before sleep/nonwear exclusion.
Age_group: age category used for subgroup analyses.
BMI_cat: BMI category derived from measured weight and height.
Race: NHANES race/ethnicity category available in the analysis data.
Gender: participant gender category available in the analysis data.
Education: coarse education category available in the analysis data.
Marital_status: marital status category available in the analysis data.
Exam_weight_recal: recalibrated 2011-2014 NHANES examination weight.
PSU: masked NHANES primary sampling unit.
Stratum: masked NHANES variance stratum.

Recommended use
Use this dataset for repeated-measure descriptions, time-of-day analyses, sensitivity checks, and linkage to participant-level summaries. Use analytic_participant_sedentary.csv for primary nationally representative participant-level sedentary-time estimates.
